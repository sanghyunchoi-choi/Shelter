# Smart Shelter — 쉘터 내부 네트워크 구성

```
┌─────────────────────────────────────────────────────────────┐
│                  쉘터 내부 LAN (192.168.0.0/24)              │
│  [관제 PC :1883,:3000] ◄──► [스위치] ◄──► [제어보드 MQTT]   │
│                              ▲                              │
│                       [공무원 PC 브라우저 :3000]             │
└─────────────────────────────────────────────────────────────┘
```

| 장치 | IP 예 | 포트 |
|------|-------|------|
| 관제 PC | 192.168.0.107 고정 | 1883, 3000 |
| 제어보드 | DHCP | → 브로커 1883 |
| 공무원 PC | 192.168.0.x | CMS 3000 |
