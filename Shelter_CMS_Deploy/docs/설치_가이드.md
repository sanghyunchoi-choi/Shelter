# Smart Shelter CMS 배포 패키지 — 설치 가이드

> **버전:** v1.0 (2026-08-12)  
> **대상:** 쉘터 내부 **관제 PC** 설치 담당자  
> **포함:** Mosquitto(1883) + CMS 웹(3000) — **소스 코드 없음**

---

## 1. 패키지 구성

| 항목 | 설명 |
|------|------|
| `install.bat` | 설치 (이미지 로드 + 기동) |
| `stop.bat` / `restart.bat` | 중지 / 재시작 |
| `images/shelter-mosquitto.tar` | MQTT 브로커 이미지 |
| `images/shelter-web.tar` | CMS 웹 이미지 |
| `docs/Shelter_Ops_Deploy.xlsx` | 네트워크 도식·체크리스트 (PPT용) |
| `docs/Shelter_Ops_Deploy_v1.0.xlsx` | rev 1.2 납품 스냅샷 |
| `docs/운영_가이드_공무원.md` | 공무원용 (브라우저만) |

---

## 2. 사전 준비

### 2.1 관제 PC

- Windows 10/11 64bit
- **Docker Desktop** 설치 및 실행
- **고정 IP(STATIC) 권장** — 예: `192.168.0.107`

### 2.2 방화벽 (관제 PC)

- TCP **1883** — 제어보드 MQTT
- TCP **3000** — 공무원 CMS

---

## 3. 설치

1. Docker Desktop 실행
2. (권장) `C:\ShelterCMS` 등 짧은 경로에 폴더 복사
3. **`install.bat`** 실행
4. **`http://localhost:3000`** 확인
5. 로그인 `smart`/`smart` → 비밀번호 변경

---

## 4. 제어보드 연동

1. PC 직결 `http://192.168.0.100` → DHCP + 브로커 = **관제 PC IP**
2. 저장 후 PC 직결 해제 → 쉘터 LAN
3. CMS ONLINE 확인

---

## 5. 공무원

- 브라우저만 → `http://관제PC_IP:3000`
- `docs/운영_가이드_공무원.md` 참고

---

## 6. 문제 해결

| 증상 | 조치 |
|------|------|
| tar 없음 | images 포함 전체 패키지 |
| CMS 안 열림 | docker ps, 방화벽 3000 |
| OFFLINE | SERVER_LAN_IP = 관제 PC IP |

```powershell
docker logs shelter-web-local
```
