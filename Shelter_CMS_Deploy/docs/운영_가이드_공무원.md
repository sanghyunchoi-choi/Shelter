# Smart Shelter CMS — 공무원 운영 가이드

> **대상:** 현장 방문 공무원

---

## 1. 공무원 PC에 필요한 것

| 필요 | 불필요 |
|------|--------|
| Chrome / Edge | Mosquitto, MQTT 프로그램 |
| 쉘터 LAN (Wi-Fi/유선) | Node.js, Docker |
| CMS 북마크 | 별도 설치 프로그램 |

---

## 2. 접속

1. 쉘터 LAN 연결
2. **`http://192.168.0.107:3000`** (관제 PC IP — 현장 확인)
3. 로그인 (초기 `smart` / `smart`)

---

## 3. CMS 기능

대시보드, 센서, 에어컨/AP/팬, 릴레이, 전원보드, 유지보수 메뉴

---

## 4. FAQ

**원격(구청) 접속?** — 기본은 쉘터 LAN 전용. VPN 별도.

**PC 설치?** — 브라우저만.

**장치 안 보임?** — 관제 PC·케이블·Docker 확인, 설치업체 문의.
