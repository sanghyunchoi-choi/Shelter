# Smart Shelter 설치 가이드 (설치 업체용)

> **버전:** v2.1 (2026-08-12)  
> **대상:** Smart Shelter 제어보드 + MOS 관제 서버  
> **관련 문서:** `Shelter_Protocol.md` (MQTT 규격), `Shelter_Protocol.xlsx` (서버 업체용)

---

## 1. 이 문서의 목적

설치 업체가 **현장·공장**에서 제어보드를 네트워크에 연결하고 **관제 CMS**에 등록하기까지의 절차를 설명합니다.

**핵심:** 최초 LAN/MQTT 설정은 **CMS 웹 화면이 아니라 PC 이더넷 직결 + 내장 설정 페이지**로 합니다.  
( IP 카메라·공유기 초기 설정과 같은 방식 )

---

## 2. 준비물

| 항목 | 설명 |
|------|------|
| 노트북 또는 PC | Windows 10/11 권장 |
| 이더넷 케이블 | PC ↔ 제어보드 직결용 (최초 설정) |
| 이더넷 케이블 | 제어보드 ↔ 현장 LAN(공유기/스위치) |
| 관제 서버 | Mosquitto + CMS 웹 (`Web_server_mosquitto`) 실행 중 |
| 전원 | 제어보드 전원 어댑터 |

**관제 서버 LAN IP**를 미리 확인하세요. (예: `192.168.0.107`)  
CMS 상단 또는 서버 관리자에게 문의.

---

## 3. IP 주소 요약

### 3.1 PC 직결 설정 시 (최초 1회)

| 장치 | IP | 서브넷 마스크 |
|------|-----|---------------|
| **제어보드** (자동) | **192.168.0.100** | 255.255.255.0 |
| **설정용 PC** | **192.168.0.10** | 255.255.255.0 |

브라우저 주소: **`http://192.168.0.100`**

### 3.2 현장 설치 후 (일반)

| 항목 | 값 |
|------|-----|
| LAN 모드 | **DHCP** (권장) — 공유기가 IP 자동 할당 |
| 제어보드 IP | 공유기 DHCP 범위 내 (예: `192.168.0.115`) |
| MQTT 브로커 | **관제 서버 LAN IP**, 포트 **1883** |

## 4. 설치 절차 (표준)

### 4.1 흐름도

```
전원 ON → PC 직결 → http://192.168.0.100 설정
    → 저장·재부팅 → ★ PC 케이블 분리 → 현장 LAN 연결 ★ → CMS ONLINE
```

> **저장 직후 재부팅:** Flash `pending=1` 상태로 **최대 2분** LAN DHCP를 기다립니다.  
> 이 구간에서 PC 직결을 유지하면 prov(`192.168.0.100`)로 **바로 돌아가지 않습니다** — **케이블을 공유기 LAN으로 옮기세요.**  
> 설정이 확정된 뒤(`pending=0`) 재설정 시: PC 직결 + 링크 UP 후 **약 5초**면 다시 `192.168.0.100` 진입.

### 4.2 Step 1 — 제어보드 전원 및 직결

1. 제어보드 전원을 켭니다.
2. PC와 제어보드를 **이더넷 케이블로 직접** 연결합니다. (공유기 불필요)
3. **케이블이 연결되어 링크 UP** 이어야 설정 모드로 진입합니다. (`Cable down` 로그면 케이블·랜포트 확인)
4. 진입 시간:
   | 상황 | 대기 |
   |------|------|
   | Flash 비어 있음 (공장) | 링크 UP + IP 없음 **5초** |
   | Flash 있음, 재설정 (`pending=0`) | 링크 UP + IP 없음 **5초** |
   | **방금 저장 직후** (`pending=1`) | LAN 연결 후 DHCP **최대 2분** (PC 직결 유지 시 prov 지연 — **Step 4 케이블 교체 필수**) |
   | MQTT 90초 실패 (공장) | 직결 fallback |

### 4.3 Step 2 — PC 네트워크 설정 (Windows)

**관리자 PowerShell**에서 이더넷 어댑터 이름 확인:

```powershell
Get-NetAdapter | Format-Table Name, InterfaceDescription, Status, LinkSpeed
```

직결 케이블이 연결된 어댑터(예: `Ethernet`)에만 IP를 설정합니다:

```powershell
# 기존 잘못된 IP 제거 (오류 무시)
Remove-NetIPAddress -InterfaceAlias "Ethernet" -Confirm:$false -ErrorAction SilentlyContinue

# 수동 IP 설정
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.0.10 -PrefixLength 24
```

설정 확인:

```powershell
Get-NetIPAddress -InterfaceAlias "Ethernet" -AddressFamily IPv4
ping 192.168.0.100
```

| 항목 | 값 |
|------|-----|
| IP | `192.168.0.10` |
| PrefixLength | `24` (= 255.255.255.0) |

> **Wi-Fi를 끈 뒤**에도 `ping 192.168.0.100`이 실패하면, IP가 **다른 어댑터**에 설정된 경우가 많습니다. `Get-NetIPAddress`로 `192.168.0.10`이 직결 이더넷에 붙었는지 반드시 확인하세요.

GUI: **설정 → 네트워크 → 이더넷 → IP 할당 → 수동** (위와 동일 값)

### 4.4 Step 3 — 브라우저 설정 페이지

1. Chrome/Edge에서 **`http://192.168.0.100`** 접속
2. **Smart Shelter 네트워크 설정** 페이지가 열립니다.
3. 아래처럼 입력 (일반 현장):

   | 항목 | 입력값 |
   |------|--------|
   | LAN 모드 | **DHCP** |
   | MQTT 브로커 IP | **관제 서버 LAN IP** (예: `192.168.0.107`) |
   | MQTT 포트 | **1883** |

4. STATIC IP가 필요한 현장만: LAN 모드를 **STATIC**으로 바꾸고 IP/SN/GW/DNS 입력

5. **[저장 및 재부팅]** 클릭  
   → Flash 저장 (`pending=1`) → 재부팅

> **DHCP 선택 시** IP 입력란(`192.168.0.50` 등)은 **저장되지 않습니다.** 고정 IP는 LAN 모드를 **STATIC**으로 선택하세요.

### 4.5 Step 4 — 현장 LAN 연결 (★ 저장 직후 필수 ★)

1. **재부팅 화면이 나오기 전에** PC 직결 케이블을 분리합니다.
2. 제어보드를 **현장 공유기/스위치 LAN 포트**에 연결합니다.
3. PC 네트워크를 **자동(DHCP)** 으로 되돌립니다.
4. 1~2분 내 DHCP + MQTT 연결 → Flash `pending=0` 확정
5. 관제 **CMS 웹** (`http://관제서버IP:3000` 등) 접속
6. 장치 목록에서 **ONLINE** 및 **UID**(24자리 HEX) 확인

> 저장 직후 PC 직결을 유지하면 **2분간** prov(`192.168.0.100`)로 돌아가지 않습니다.  
> LAN으로 케이블을 옮기지 않으면 DHCP를 받지 못해 CMS에 안 붙습니다.

### 4.6 Step 5 — 설치 확인 체크리스트

- [ ] CMS에서 제어보드 **ONLINE**
- [ ] `dev/tele/state` — `status: ONLINE`, `uid` 표시
- [ ] 먼지/온습도 등 센서 tele 수신 (연결된 경우)
- [ ] 전원보드(PB) 연결 시 전력 데이터 표시
- [ ] UID 라벨과 CMS UID 일치

## 5. 공장·양산 공정 (제조사)

동일 펌웨어를 모든 unit에 플래시한 뒤:

| 순서 | 작업 |
|------|------|
| 1 | 공통 펌웨어 플래시 |
| 2 | PC 직결 → `http://192.168.0.100` |
| 3 | DHCP + **양산 서버 브로커 IP** 저장 |
| 4 | 테스트 LAN 연결 → CMS ONLINE 확인 |
| 5 | UID 라벨 부착 → 출하 |

현장에서 브로커 IP가 다르면 설치 업체가 Step 3~4를 현장에서 다시 수행합니다.

---

## 6. 고정 IP(STATIC) 현장

공유기 DHCP를 쓸 수 없는 경우:

1. 직결 설정 페이지에서 LAN 모드 **STATIC**
2. 현장에서 부여받은 IP/SN/GW/DNS 입력
3. 브로커 IP/포트 입력 후 저장

---

## 7. 공장 초기화 (설정 전체 삭제)

| 방법 | 설명 |
|------|------|
| **SW8** (제어보드 스위치) | Flash erase → DHCP + 공장 기본값 |
| CMS 유지보수 | Flash Reset → DHCP 복귀 (이미 ONLINE일 때) |

초기화 후에는 **섹션 4** 직결 설정을 다시 진행합니다.

## 8. 문제 해결

### 8.1 `http://192.168.0.100` / ping 실패 (`ERR_ADDRESS_UNREACHABLE`)

| 확인 | 조치 |
|------|------|
| PC IP가 **직결 이더넷**에 `192.168.0.10/24` | `Get-NetIPAddress`로 어댑터 확인 |
| Wi-Fi 끄기 | Wi-Fi에 192.168.0.x가 남아 있으면 경로 꼬임 |
| 시리얼 `[PROV] alive link=1 IP=192.168.0.100` | 10초마다 출력 — 보드 정상 대기 중 |
| `HTTP_SR=0x14` | LISTEN 정상 |
| USB 허브/도킹 이더넷 | 내장 LAN 포트로 직결 권장 |
| 미니 스위치 경유 | PC–스위치–보드 3-way로도 가능 (Auto-MDIX) |

### 8.2 설정 저장 후 CMS에 안 보임

| 확인 | 조치 |
|------|------|
| **저장 후 PC 직결 유지** | 케이블을 **공유기 LAN**으로 옮긴 뒤 1~2분 대기 (`pending=1` 구간) |
| 브로커 IP 오타 | PC 직결 재설정 (`pending=0`이면 5초 후 `192.168.0.100`) |
| 제어보드가 현장 LAN에 연결됨 | 공유기 LAN 포트 확인 |
| 서버 Mosquitto 실행 중 | 서버 관리자 확인 |
| PC와 제어보드 같은 LAN | 라우터/스위치 경로 확인 |

### 8.2a 저장 직후 `192.168.0.100` 진입 안 됨

| 로그 | 의미 | 조치 |
|------|------|------|
| `[PROV] Config just saved — unplug PC...` | 저장 직후 2분 DHCP 유예 | **정상** — PC 케이블 분리 후 공유기 LAN 연결 |
| `[PROV] Flash config loaded — PC direct... in 5s` | 재설정 모드 | PC `192.168.0.10` + 케이블 직결, 5초 대기 |
| `[WAIT] Cable down` | 링크 없음 | 이더넷 케이블·랜 LED 확인 |
| `pending=1` + PC 직결 | prov 2분 지연 | LAN으로 교체하거나, MQTT ONLINE 후 재설정 |

### 8.3 잘못된 IP 입력 후 접속 두절

- 제어보드는 **60초 내 MQTT 실패 시 자동 롤백** (최대 3회)  
- 복구 안 되면 **SW8** 또는 PC 직결로 재설정
